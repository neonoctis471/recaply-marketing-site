# Recaply — AI Meeting Notes Marketing Website

Recaply is a responsive concept marketing website for an AI meeting-notes product. It turns the idea of a meeting recap into a clear, interactive product story: individual speaker moments connect to a concise summary and a practical next step.

## About the project

The visual direction avoids the familiar purple-gradient AI aesthetic. Instead, the site uses warm ivory surfaces, crisp blue accents, muted sage details, editorial typography, and a realistic layered-paper interface inspired by physical meeting notes.

The redesigned hero document includes paper texture, offset sheets, contact shadows, metal clip details, handwritten annotations, and a folded corner. These physical details make the product preview feel tactile while preserving the original interactive behavior.

## Highlights

- Interactive meeting recap with synchronized summary and next-step content
- Realistic layered-paper hero interface with subtle pointer movement
- Product preview tabs and feature exploration
- Responsive layouts for desktop, tablet, and mobile
- Pricing, FAQ accordion, final call to action, and mobile navigation
- Keyboard-friendly controls, visible focus states, and reduced-motion support
- Restrained micro-interactions designed to support the content
